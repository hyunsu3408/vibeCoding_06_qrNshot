# QuickLink & QR (QR코드 & URL단축 올인원 웹 애플리케이션)

> 빠르고 간편하게 URL을 단축하고, 고화질 QR코드를 즉시 생성하여 다운로드할 수 있는 통합 웹 솔루션입니다.

## 🚀 시작하기

별도의 웹 서버 설치나 빌드 과정 없이, 브라우저에서 `index.html`을 더블 클릭하여 즉시 실행할 수 있습니다.

- **통합 메인 포털**: `index.html`
- **QR코드 생성기**: `url2qr/index.html`
- **URL 단축기**: `urlShort/index.html`

---

## ✨ 핵심 기능

### 1. 상단 네비게이션
- 모든 화면 상단에 **'QR코드'** 버튼과 **'URL단축'** 버튼이 배치되어 원클릭으로 이동 가능합니다.
- 현재 위치한 서비스 탭이 시각적으로 강조(`active`)됩니다.

### 2. URL 단축 기능 (`urlShort/`)
- **URL 입력 필드**: 긴 웹 주소를 입력하면 실시간으로 감지합니다.
- **버튼 자동 활성화/비활성화**: 입력창이 비어 있으면 '단축하기' 버튼이 비활성화되며, 텍스트가 입력되면 자동으로 활성화됩니다.
- **OpenAPI 초고속 단축**: is.gd / v.gd / TinyURL 다중 백엔드 OpenAPI를 연동하여 안전하고 빠르게 단축 URL을 생성합니다.
- **읽기 전용 출력 상자**: 단축된 URL이 읽기 전용 상자에 안전하게 표시되며 클릭 시 전체 선택됩니다.
- **원클릭 복사 & 알림**: '복사' 버튼을 누르면 클립보드에 자동 복사되고 `복사하였습니다.` 알림창이 팝업됩니다.
- **QR코드 연계**: 생성된 단축 URL을 원클릭으로 QR코드 생성기에 넘겨 즉시 QR코드를 만들 수 있습니다.

### 3. QR코드 생성 기능 (`url2qr/`)
- 입력된 URL을 256x256 고화질 QR코드로 즉시 렌더링합니다.
- QR코드 클릭 또는 다운로드 버튼을 통해 고화질 JPG 이미지로 다운로드할 수 있습니다.
